# Feature requests

The owner's list of things to add. **Add new items at the bottom of "Open"**, in any language, one line
is enough. The team reads this file whenever it picks the next piece of work, moves items to
"In progress" when started and to "Done" with a short note when shipped.

Priority hints (optional): `P1` = next, `P2` = soon (default), `P3` = nice to have.

## Open

- P2 · **Polish animations across most meaningful user actions** in Dot Mail, using subtle, fast, consistent Quiet UI motion: navigation and screen transitions; mail row insertion/removal on archive, delete, restore and refresh; swipe feedback; selection and contextual-action transitions; conversation expand/collapse; buttons, sheets, menus, dialogs and loading states. **Specifically animate the Cc and Bcc recipient fields in Compose when the user taps “Cc/Bcc”**: smoothly reveal and collapse the rows with coordinated height/opacity/position changes, reflow surrounding content without jumps, and keep keyboard focus and accessibility correct. Prefer native Jetpack Compose animations, smooth 60/120 Hz behavior and reduced-motion accessibility settings; avoid excessive motion, delays, flashy effects or animations on every trivial interaction.

- P1 · Mirror drafts with the server's Drafts folder so edits are available across devices; handle offline edits and conflicts safely.

- P2 · Per-account and per-folder notification rules, including muting conversations and configurable notification actions.
- P2 · Optional native Android Contacts integration (contact picker/autocomplete/photos without requiring blanket contacts access).
- P2 · Advanced inbox sorting, filters and configurable smart folders across accounts.
- P2 · Dedicated attachment browser across accounts, with type/date/sender filters, full attachment search, preview, export and Android sharing.

- P2 · PDF/document attachment preview with local text extraction where practical; convenient Android share-to-Paperless-ngx workflow, with any direct integration strictly optional.

- P2 · Establish a restrained Quiet UI button hierarchy inspired by ChatGPT/Grok: **Primary/confirmatory actions** (Send, Save, Confirm) use a solid Accent Blue fill with clear contrast and rounded geometry, **not glass**; **floating actions** (especially the oversized Compose/New email button, and only a few contextual floating controls) use a compact fully rounded **Soft Frosted Pill** with a translucent graphite surface, very soft highlight, delicate low-contrast border, minimal elevation and no neon/glow; **secondary/navigation actions** (Archive, Reply, Forward, toolbar icons, settings, menus, list rows) remain flat or subtly surfaced. Keep Compose small without sacrificing discoverability, one-handed access or >=48dp touch targets. Use glass sparingly as a floating/elevation accent, never as the universal button style; do not combine Accent Blue and glass by default. **Glass communicates elevation; blue communicates priority.**

- P2 · Add an **optional horizontal swipe gesture inside the opened email reader** to navigate to the next or previous message/conversation in the current mailbox, without returning to the inbox. Provide a clear Settings toggle (off/on) and configurable swipe direction if appropriate; preserve reading position and offer a subtle transition/haptic feedback. Do not interfere with Android's system Back gesture, horizontal scrolling of HTML content, carousels, text selection, or attachment interactions. Keep the existing previous/next controls available.

- P2 · Add **native-feeling pinch-to-zoom for HTML emails** in the message reader: smooth two-finger scaling in and out, panning when zoomed, double-tap zoom/reset if feasible, and a sensible maximum/minimum scale. Default rendering must still **fit the available screen width** without clipping; zoom is an optional reading aid, not a workaround for broken HTML layout. Ensure zoom gestures coexist correctly with vertical scrolling, optional horizontal swipes between messages, text selection, attachments and Android edge-back gestures. Make zoom behavior configurable in Settings if appropriate, and verify on a real device against Gmail/Samsung Email.
