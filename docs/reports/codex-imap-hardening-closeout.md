## Validation

The initial five-test regression run had four expected failures; the local-lock test already passed. The independent saved-search scope regression then also failed before its fix. Targeted tests passed after the changes, including the IDLE timeout fixture. Full `scripts/gw :mail:test :data:testDebugUnitTest :app:assembleDebug` results and the final rebased revision are recorded in the PR. Tests use fixture mail/GreenMail and Robolectric; no real mailbox or phone was accessed.

The change adds only DAO queries/projections; the Room v9 schema remains unchanged. Preview fetches remain BODY.PEEK and bounded, while full-body/attachment loads stay on demand or explicit offline policy. No timing percentages or live-device performance claims are inferred from query-count tests.

## Retroactive repair: separate approved follow-up

Per Claude's explicit decision, this PR closes the forward behavior. A separate one-time, idempotent pass will split groups merged only by the old faulty rules. The component containing the oldest message retains the original thread ID; split components get new IDs, and existing snooze/mute state is copied to them. That follow-up will use a fixture database containing the faulty merges and interruption/idempotence tests. The forward PR does not silently change existing conversation IDs.
